## Cloud-Native
## Setup
**Step 1.** Start an SSH authentication agent and add your SSH private to it. 
```bash
eval "$(ssh-agent -s)" # starts the SSH authentication agent
ssh-add ~/.ssh/id_rsa  # adds your SSH private key to the SSH authentication agent
```

**Step 2.** Install Ansible if you don't already have it installed.
```bash
sudo python -m pip install ansible
```

## Task 01
In this task, you're going to deploy and configure a virtual machine in Azure using Terraform and Ansible. Next, you're going login to it and use Packer to create custom a virtual machine image. Then, you're going to deploy a new virtual machine instance using the custom image. 

**Step 1.** Deploy a virtual machine in Azure using the provided Terraform files. Notably, they also create a resource group, service principal, and role assignment for Packer.   
```bash
terraform -chdir=terraform init
terraform -chdir=terraform plan
terraform -chdir=terraform apply -auto-approve
export USERNAME=$(terraform -chdir=terraform output -raw username)
export IP_ADDRESS=$(terraform -chdir=terraform output -raw ip_address)
export TENANT_ID=$(terraform -chdir=terraform output -raw tenant_id)
export SUBSCRIPTION_ID=$(terraform -chdir=terraform output -raw subscription_id)
export PACKER_CLIENT_ID=$(terraform -chdir=terraform output -raw service_principal_client_id)
export PACKER_CLIENT_SECRET=$(terraform -chdir=terraform output -raw service_principal_client_secret)
```

**Step 2.** Configure to the virtual machine using Ansible. The playbook provided references multiple scripts in the [`ansible/scripts`](task-01/ansible/scripts/) folder. They include installing Terraform, Packer, Azure CLI, Docker, Kubectl, Helm, etc. The source code for this week's project is also automatically downloaded.  
```bash
ansible-playbook ansible/playbook.yaml -u $USERNAME -i ansible/inventory.yaml --ssh-common-args='-o StrictHostKeyChecking=no'
```

**Step 3.** Login to the virtual machine. 
```bash
ssh $USERNAME@$IP_ADDRESS
```

**Step 4.** Login to the Azure CLI from the virtual machine and set your subscription.
```bash
az login --use-device-code
az account set --subscription "AI2C Subscription 1"
```

**Step 5.** Change directories to `~/handout/cloudchat/terraform-setup/task1-monolith_data_tier`.
```bash
cd ~/handout/cloudchat/terraform-setup/task1-monolith_data_tier
```

**Step 6.** Initialize a Terraform configuration and create an execution plan. Provide a database administrator password when prompted (e.g., `Password123!`). 
```bash
terraform init
terraform plan
```

**Step 7.** Apply the Terraform execution plan and use `secret.tfvars` as the source of your variables. 
```bash
terraform apply -var-file="secret.tfvars" -auto-approve
```

**Step 8.** Create a BASH script to print the variables generated by the previous step. 
```bash
vim print-env-vars.sh 
```
```bash
# copy and paste the commands below to the file above
echo "export MYSQL_HOST='$(terraform output -raw mysql_fqdn)'"
echo "export MYSQL_USER='$(terraform output -raw mysql_admin_username)'"
echo "export MYSQL_PASSWORD='$(terraform output -raw mysql_admin_password)'""
```

**Step 9**. Run the BASH script from the `task1-monolith_data_tier` directory and copy the output to `run_monolith.sh` in the `~/handout/cloudchat/task1-monolith/packer` directory.
```bash
bash print-env-vars.sh
```
```bash

export MYSQL_USER='Monolithic_CloudChat_123'
export MYSQL_PASSWORD='Monolithic_CloudChat_123'
export SPRING_REDIS_HOST='redis-cache-vpxufblg.redis.cache.windows.net'
export SPRING_REDIS_PASSWORD='d5OkJ91ujR320LQJcziHXBTlozDdKultqAzCaENFU28='
export SPRING_REDIS_PORT='6379'
```

**Step 10.** Change directories to `~/handout/cloudchat/task1-monolith/packer`.
```bash
cd ~/handout/cloudchat/task1-monolith/packer
```

**Step 11.** Edit `azure-packer.pkr.hcl` using the [provided example](task-01/packer/azure-packer.pkr.hcl).
```bash
vim azure-packer.pkr.hcl
```

**Step 12.** Create `variables.pkr.hcl` using the [provided example](task-01/packer/variables.pkr.hcl).
```bash
vim variables.pkr.hcl
```

**Step 13.** Edit `secret.pkrvars.hcl` using the [provided example](task-01/packer/secret.pkvars.hcl).
```bash
vim secret.pkrvars.hcl 
```

**Step 14.** Initialize Packer.
```bash
# make sure you're in this folder: handout/cloudchat/task1-monolith/packer
packer init .
```

**Step 15.** Validate your Packer configuration.
```bash
packer validate -var-file="secret.pkrvars.hcl" -var "managed_image_name=demo-01" .
```

**Step 16.** Build your Packer configuration. The image will be put into the resource group defined in your `variables.pkr.hcl` file (e.g., `cloud-native-week-01-packer`).
```bash
packer build -var-file="secret.pkrvars.hcl" -var "managed_image_name=demo-01" .
```

**Step 17.** Verify the virtual machine image works.  
```bash
az vm create \
  --resource-group "cloud-native-week-01-packer" \
  --name "demo-01" \
  --image "demo-01" \
  --admin-username "azureuser" \
  --generate-ssh-keys
```

chmod +x submitter
./submitter -task1

## Task 02
In this task, you're going to deploy a SQL database in Azure using Terraform. Then, you're going to create a Docker container that uses the SQL database. 

**Step 1.** Login to the very first virtual machine you created in Task 01.
```bash
ssh $USERNAME@$IP_ADDRESS
```

**Step 2.** Login to the Azure CLI from the virtual machine and set your subscription.
```bash
az login --use-device-code
az account set --subscription "AI2C Subscription 1"
```

**Step 3.** Change directories to `~/handout/cloudchat/terraform-setup/task2-3-profile_data_tier`.
```bash
cd ~/handout/cloudchat/terraform-setup/task2-3-profile_data_tier
```

**Step 4.** Initialize the Terraform configuration in the `task2-3-profile_data_tier` directory and create an execution plan. Provide a database administrator password when prompted (e.g., `Password123!`). 
```bash
terraform init
terraform plan
```

**Step 5.** Apply the Terraform execution plan and use `secret.tfvars` as the source of your variables. 
```bash
terraform apply -var-file="secret.tfvars" -auto-approve
```

**Step 6.** Create a BASH script in the `task2-3-profile_data_tier` directory to print the variables generated by the previous step. 
```bash
vim print-env-vars.sh 
```
```bash
# copy and paste the commands below to the file above
echo "MYSQL_DB_HOST=$(terraform output -raw mysql_fqdn)"
echo "MYSQL_DB_PORT=3306"
echo "MYSQL_DB_USER=$(terraform output -raw mysql_admin_username)"
echo "MYSQL_DB_PASSWORD=$(terraform output -raw mysql_admin_password)"
```

**Step 7**. Run the BASH script from the `task2-3-profile_data_tier` directory and copy the output to `.env` in the `~/handout/cloudchat/task2-4-microservices/profile/task2-docker` directory.
```bash
bash print-env-vars.sh
```
```bash
# output
MYSQL_DB_HOST=profile-mysql-fs-tywshqsk.mysql.database.azure.com
MYSQL_DB_PORT=3306
MYSQL_DB_USER=CloudChat_Profile_123
MYSQL_DB_PASSWORD='CloudChat_Profile_123
```

**Step 8.** Change directories to `~/handout/cloudchat/task2-4-microservices/profile/`.
```bash
cd ~/handout/cloudchat/task2-4-microservices/profile/
```

**Step 9.** Edit `Dockerfile` in the `task2-docker` directory using the [provided example](task-02/Dockerfile).
```bash
vim task2-docker/Dockerfile
```

**Step 10.** Edit `.env` in the `task2-docker` directory using the [provided example](task-02/.env).
```bash
vim task2-docker/.env
```

**Step 11.** Build and tag a container image using the `Dockerfile` you just edited. 
```bash
sudo docker build -f task2-docker/Dockerfile -t cloudchat/profile:v1.0.0 .
```

**Step 12.** Create a container using the container image you just built and the `.env` you edited. 
```bash
sudo docker run --name profile --env-file task2-docker/.env -p 8000:8080 cloudchat/profile:v1.0.0
```

**Step 13.** Verify the container is working. 
```bash
curl localhost:8000/profile?username="goober"
# the word "null" will be printed to the console 
```

**Misc.** These Docker commands are helpful when troubleshooting.
```bash
sudo docker container ls -a                   # check what containers exist
sudo docker container rm profile              # remove the container with the name of "profile"
sudo docker image ls                          # check what images exist
sudo docker image rm cloudchat/profile:v1.0.0 # remove the image tagged "cloudchat/profile:v1.0.0" (repo/image:version)
```
