# Week 10
## Debugging, Refactoring, Testing, Packaging

**Debugging**  
Debugging is the process of diagnosing and fixing errors. 

**Refactoring**  
Refactoring is the process of rewriting code to improve its modularity, usability and maintainability

## Training Objectives
* Debug an error relating to predictable code behavior
* Debug an error relating to updating an object
* Refactor code
  * Update folder structure
  * Update import paths
  * Update class methods in existing modules
  * Add a `__init__.py` file to define a new module
