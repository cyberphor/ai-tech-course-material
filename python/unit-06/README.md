## Setup
**Step 1.** Download the source code provided.
```bash
wget https://principlesofcomputing.blob.core.windows.net/ppp-p5-debug-refactor-test-package/handout/sail2/ppp-p5-debug-refactor-test-package.zip
unzip ppp-p5-debug-refactor-test-package.zip
```

**Step 2.** Create a virtual environment. 
```bash
cd ppp-p5-debug-refactor-test-package
python -m venv p5-env
source p5-env/bin/activate
```

**Step 3.** Install the requirements. 
```bash
python -m pip install -r requirements.txt
```
