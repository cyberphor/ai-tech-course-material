# Containers: Docker and Kubernetes

## Apps
An app consists of a frontend, backend, and database. The backend component represents the business logic of the app. 

## App Architecture Styles
There are two app architecture styles: monolith or microservice. 

**Monolith**  
Monolithic apps combine their components.

**Microservice**   
Microservice apps separate their components. Microservice apps usually package their components into containers. 

## Docker
Docker is a tool for building images and managing containers. It includes the Docker CLI, Docker Engine, and Docker Engine API.

**Image**  
An image is an executable program that contains everything needed to run an app (e.g., source code, runtime, and software libraries). 

**Container**  
A container is an instance of an image. If an image is a program, a container is the procress created when the program is executed.

**Docker Engine**  
The Docker Engine builds images using Dockerfiles.

**Dockerfile**  
A Dockerfile is a set of instructions for building an image.
